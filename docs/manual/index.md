## アプリ全体の概念

| 用語             | 説明                                                   |
| ---------------- | ------------------------------------------------------ |
| **取引先**       | 警備サービスを発注する顧客企業                         |
| **現場**         | 警備業務を行う拠点・場所。取引先に紐づく               |
| **従業員**       | 自社に所属する警備員                                   |
| **外注先**       | 警備員を派遣してもらう外部の会社・個人                 |
| **稼働予定**     | 現場ごとの稼働スケジュール（日付・勤務区分・必要人数） |
| **稼働実績**     | 実際に行われた警備業務の記録。売上の元データ           |
| **取極め**       | 稼働に対して適用する単価・計算ルールの設定             |
| **稼働請求**     | 稼働実績ごとの請求情報                                 |
| **取引先請求**   | 取引先・現場単位でまとめた月次請求書                   |
| **商品（明細）** | 稼働に付随する追加請求項目（貸与品など）               |
| **配置通知**     | 作業員に対して稼働予定の情報を通知するドキュメント     |
