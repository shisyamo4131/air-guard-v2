# 従業員管理

**ナビゲーション:** 従業員管理

自社に所属する従業員（警備員）の情報を管理します。

---

## 在職者一覧

**URL:** `/employees`  
**ナビゲーション:** 従業員管理 > 在職者一覧

### 概要

在職中の従業員を一覧で表示します。キーワード検索で絞り込みが可能です。一覧はフリガナ順で表示されます。

### 画面操作

| 操作     | 説明                                                   |
| -------- | ------------------------------------------------------ |
| 検索     | 検索ボックスにキーワードを入力して従業員を絞り込みます |
| 新規作成 | 一覧上部の追加ボタンから従業員を新規登録できます       |
| 詳細表示 | 一覧の行をクリックすると詳細画面へ遷移します           |

---

## 従業員詳細

**URL:** `/employees/{id}`

### 概要

従業員の詳細情報を確認・編集します。基本情報から保険・資格情報まで一括管理できます。

> **注意:** 退職済みの従業員の詳細を表示すると、画面上部に警告が表示されます。

### 画面レイアウト

#### 左カラム

**基本情報**  
氏名、生年月日、住所、連絡先などの基本情報を表示・編集します。

「退職処理」ボタンから退職手続きを行えます。  
ユーザーアカウントが紐づいている従業員（アプリのアカウントを持つ従業員）は退職処理ができません。

**国籍情報**  
従業員の国籍に関する情報を表示・編集します。

**ユーザー情報**（在職中の場合のみ）  
従業員をアプリのユーザーアカウントと紐づけるための情報を管理します。  
アカウントが紐づいている従業員は、アプリにサインインして自身の配置通知などを確認できます。

#### 右カラム

**雇用保険 / 健康保険 / 厚生年金**  
各保険の加入・変更・脱退の履歴を管理します。  
現在の加入状況と変更の記録が一覧で確認できます。

**警備員資格情報**  
警備員として必要な登録情報（緊急連絡先・血液型など）を管理します。  
未登録の場合は登録を促すメッセージが表示されます。

**保有資格**  
従業員が保有する警備関連の資格を管理します。

### 退職処理

「退職処理」ボタンをクリックすると、退職日と退職理由を入力して退職処理を実行できます。退職処理が完了すると、在職者一覧から非表示になり[退職者検索](#退職者検索)で検索できるようになります。

> **注意:** アプリのユーザーアカウントが紐づいている従業員は退職処理できません。先にユーザーアカウントとの紐づけを解除してください。

### 従業員の削除

画面最下部の「この従業員を削除する」ボタンから削除できます。

> **注意事項:**
>
> - 削除すると復元することはできません。
> - ユーザーアカウントが紐づいている従業員は削除できません。

## 退職者検索

**URL:** `/employees/resigned`  
**ナビゲーション:** 従業員管理 > 退職者検索

### 概要

退職済みの従業員をキーワード検索で検索します。  
検索ボックスが空の状態では、最近更新された10件が表示されます。

### 退職者の詳細表示

一覧の行をクリックすると詳細画面へ遷移します（在職者と同じ詳細画面が開きます）。
