# 請求管理

**ナビゲーション:** 請求管理

稼働実績に基づく請求情報を管理します。  
請求管理は「稼働請求管理」と「取引先請求管理」の2つの画面で構成されています。

---

## 稼働請求管理（稼働請求一覧）

**URL:** `/billings/operations`  
**ナビゲーション:** 請求管理 > 稼働請求一覧

### 概要

稼働実績ごとの請求情報を確認・調整します。  
稼働に関わらない請求項目（貸与品など）の追加や、請求単価の調整もこの画面で行います。

> **注意:** この画面から新規の稼働請求データを作成することは**できません**。稼働請求データは必ず[稼働実績管理](./operation-results.md)から作成してください。

### 画面操作

| 操作         | 説明                                                           |
| ------------ | -------------------------------------------------------------- |
| 月の切り替え | ツールバーの月セレクターで表示月を変更します（初期表示は当月） |
| 詳細表示     | 一覧の編集ボタンをクリックすると詳細画面へ遷移します           |

---

## 稼働請求詳細

**URL:** `/billings/operations/{id}`

### 概要

稼働請求の詳細情報を確認・編集します。

### 画面レイアウト

#### 左カラム

**稼働概要**  
稼働日、現場、勤務区分などの基本情報を表示します。

**警備日報**  
この稼働に紐づく警備日報を確認できます。

#### 右カラム

**取極め・請求締日**  
適用されている取極め（単価設定）と請求締日を確認できます。

**請求明細**  
稼働に対する請求明細（通常・資格者の配置数、売上金額など）を確認・調整できます。  
請求単価を直接変更したり、調整額として請求単価を変更したりすることが可能です。

**明細（追加請求項目）**  
稼働に付随する追加請求項目（貸与品など）を管理します。

**作業員**  
この稼働に配置された作業員（従業員・外注先）の一覧を表示します（参照のみ）。

### 稼働実績のロック

この画面で稼働実績を**ロック**すると、[稼働実績管理](./operation-results.md)での編集・削除ができなくなります。請求内容が確定したタイミングでロックしてください。

### 消費税・端数処理について

- 稼働実績の日付から適用税率を判定し、請求書内の税率別税抜売上合計に対して消費税を計算します。
- 現場別請求書と取引先統合請求書は、それぞれの請求書全体を税率別に集計して端数処理します。
- 集計単位が異なるため、各現場別請求書の消費税額合計と取引先統合請求書の消費税額が一致しない場合があります。
- 売上金額の端数処理は会社設定の端数処理設定に従います。

## 取引先請求管理（取引先請求一覧）

**URL:** `/billings/customers`  
**ナビゲーション:** 請求管理 > 取引先請求一覧

### 概要

取引先・現場単位で集計された月次請求情報を一覧で確認します。  
請求書PDFのダウンロードがメインの機能です。

### 画面操作

| 操作                  | 説明                                                                                                 |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| 月の切り替え          | ツールバーの月セレクターで表示月を変更します                                                         |
| PDF出力（現場単位）   | 各行の PDFアイコンボタンをクリックすると現場単位の請求書を出力します                                 |
| PDF出力（取引先単位） | 取引先のグループヘッダーの PDFアイコンボタンをクリックすると取引先全現場をまとめた請求書を出力します |
| 詳細表示              | 各行の編集アイコンをクリックすると詳細画面へ遷移します                                               |

## 取引先請求詳細

**URL:** `/billings/customers/{id}`

### 概要

取引先・現場単位の請求情報の詳細を確認します。

### 表示内容

| 項目       | 説明                                           |
| ---------- | ---------------------------------------------- |
| 取引先     | 請求先の取引先名                               |
| 現場       | 対象の現場名                                   |
| 請求日     | この請求の請求日                               |
| 売上金額   | 税抜の売上合計額                               |
| 消費税額   | 消費税の合計額                                 |
| 請求額     | 税込の請求合計額                               |
| 入金予定日 | 支払期日（変更可能）                           |
| 稼働実績   | 集計対象の稼働実績の一覧（日付・配置数・売上） |

### 入金予定日の変更

入金予定日の横にある「変更」ボタンをクリックすると、入金予定日を個別に変更できます。

> **補足:** 入金予定日は通常、取引先に設定された入金サイト（締日から起算した支払期日）に基づいて自動計算されます。一度設定された後に取引先の入金サイトを変更しても現在の請求データには反映されません。個別に変更する場合はこの画面で操作してください。
