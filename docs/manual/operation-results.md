# 稼働実績管理

**ナビゲーション:** 稼働実績管理

売上データのもととなる稼働実績情報を管理します。

---

## 稼働実績一覧

**URL:** `/operation-results`  
**ナビゲーション:** 稼働実績管理 > 稼働実績一覧

### 概要

登録されている稼働実績を一覧で確認します。月単位でフィルタリングできます。

### 画面操作

| 操作         | 説明                                                             |
| ------------ | ---------------------------------------------------------------- |
| 月の切り替え | ツールバーの月セレクターで表示月を変更できます（初期表示は当月） |
| 新規作成     | 一覧上部の追加ボタンから稼働実績を手動で新規作成できます         |
| 詳細表示     | 一覧の行をクリックすると詳細画面へ遷移します                     |

### 稼働実績の作成方法

稼働実績は以下の2通りの方法で作成されます。

1. **[上下番確定処理](./control-operation.md)** による自動作成（推奨）
2. この画面からの**手動作成**

> **注意:** 手動で作成した場合、取極めは自動で適用されません。

---

## 稼働実績詳細

**URL:** `/operation-results/{id}`

### 概要

稼働実績の詳細情報を確認・編集します。

### 画面レイアウト

#### 左カラム

**基本情報**  
稼働日、現場、勤務区分（日勤/夜勤）などの基本情報を表示・編集します。

> **注意:** 稼働請求管理でロックされた実績は編集できません（ロック時は画面上部に警告が表示されます）。

#### 右カラム

**作業員**  
この稼働に配置された従業員・外注先の一覧を管理します。追加・削除が可能です。

**明細**  
稼働に付随する追加請求項目（貸与品など）を管理します。

**警備日報**  
この稼働に紐づく警備日報を確認・管理します。

### 稼働実績の削除

画面最下部の「この稼働実績を削除する」ボタンから削除できます。

> **注意事項:**
>
> - 稼働請求管理でロックされた実績は削除できません。
> - 上下番確定処理で登録された稼働実績を削除すると、元に戻すことはできません。
> - 稼働日や勤務区分などを変更すると、作業員（特に従業員）の勤怠実績も連動して変更されます。注意して操作してください。
> - 稼働実績の現場を変更することはできません（適用されている取極めが変わってしまうため）。

### 取極めの取り扱い

稼働実績に対する売上は、原則として取極めをもとに計上されます。以下のケースに対応しています。

| ケース                       | 取極め | 取極めなしを無視 | 実績確定 | 稼働売上 |
| ---------------------------- | ------ | ---------------- | -------- | -------- |
| 通常                         | あり   | －               | 可能     | あり     |
| 取極め未定                   | なし   | －               | 不可     | 0円      |
| 取極めなし（稼働の記録のみ） | なし   | チェック         | 可能     | 0円      |
