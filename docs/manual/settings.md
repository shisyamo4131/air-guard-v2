# 管理者メニュー

**ナビゲーション:** 管理者メニュー

管理者ロールを持つユーザーのみアクセスできる設定画面です。

---

## 会社設定

**URL:** `/settings/company`  
**ナビゲーション:** 管理者メニュー > 会社設定

### 概要

自社の情報や各種設定を管理します。

### 画面レイアウト

#### 左カラム

**基本情報**  
会社名、住所、電話番号などの基本情報を表示・編集します。

**口座情報**  
振込先口座の情報を登録します。請求書PDFへの印刷に使用されます。

**設定情報**  
アプリの動作に関わる各種設定を変更します。

#### 右カラム

**取極め情報（会社デフォルト）**  
会社全体に適用するデフォルトの取極め（稼働単価・計算ルール）を設定できます。  
現場ごとの取極めが設定されていない場合の基準として使用されます。

---

## ユーザー設定

**URL:** `/settings/users`  
**ナビゲーション:** 管理者メニュー > ユーザー設定

### 概要

このテナントに所属するユーザーアカウントの一覧を表示・管理します。

### 主な操作

| 操作               | 説明                                                               |
| ------------------ | ------------------------------------------------------------------ |
| 一覧表示           | 登録されているユーザーをメールアドレス順で一覧表示します           |
| ユーザーの追加     | 一覧上部の追加ボタンから新規ユーザーを招待・作成できます           |
| ユーザー情報の編集 | 一覧からユーザーを選択して情報を編集できます（ロール・表示名など） |

### ユーザーロールについて

ユーザーに付与するロールにより、アクセスできる画面・操作が制限されます。  
ロールの設定はシステム管理者に確認してください。
