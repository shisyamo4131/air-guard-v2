# 管理者メニュー

**ナビゲーション:** 管理者メニュー

本人設定は有効な本登録ユーザーが利用できます。会社設定ページ自体は会社管理者とスーパーユーザーに表示されますが、基本情報と振込先の編集は同じ会社の有効な本登録会社管理者だけに表示され、スーパーユーザーは編集できません。ユーザー管理設定は会社管理者または`manager`ロールから`users:write`を得るユーザーに表示され、直接permission文字列やスーパーユーザー属性だけでは表示されません。退職・アカウント削除履歴は会社管理者だけに表示され、スーパーユーザーを含む他のロールには表示されません。

---

## 本人設定

**ナビゲーション:** 画面上部のアカウント設定アイコン

有効な本登録ユーザーは、自分の表示名とタグサイズを変更できます。保存後に設定画面を開き直すと、更新した値が表示されます。メールアドレス、ロール、通知受信設定、管理状態はこの画面から変更できません。

---

## 会社設定

**URL:** `/settings/company`  
**ナビゲーション:** 管理者メニュー > 会社設定

### 概要

自社の情報や各種設定を管理します。この節は現在画面の操作説明です。基本情報、振込先、通常設定は専用の安全な保存処理へ移行済みです。Company既定取極めの編集入口は廃止しました。配置管理と稼働予定の表示順も専用の保存処理へ移行しています。

### 画面レイアウト

**基本情報**  
会社名、住所、電話番号などの基本情報を表示・編集します。保存中は入力欄とすべての操作ボタンが使用できなくなります。自分の保存結果では外部更新の警告を表示せず、本当に別の画面で変更された場合だけ最新値の再読込を求めます。

**口座情報**  
振込先口座の情報を登録します。銀行名、支店名、口座種別、口座番号、口座名義の5項目をすべて入力して保存してください。一部だけの保存はできません。登録をやめる場合は「振込先をすべて削除」を使います。保存中は入力欄とすべての操作ボタンが使用できなくなります。編集中に本当に別画面で変更された場合は保存できないため、「最新値を読み直す」後に入力し直します。自分の保存結果ではこの警告は表示されません。有効な5項目がそろった振込先だけが口座名義込みで請求書PDFへ印刷されます。

**設定情報**  
会社管理者は、時刻選択間隔、端数処理、週の開始曜日、勤怠管理方式を変更できます。時刻選択間隔は5〜30分を5分単位で指定します。保存中は入力欄、選択欄、取消、保存、閉じる操作が使用できません。自分の保存結果では外部更新警告を表示せず、本当に別の画面で通常設定が変わった場合だけ最新値の再読込を求めます。

利用者の実際の利用環境では、次を最終確認します。

1. 会社管理者に通常設定の編集ボタンが表示され、4項目の現在値が表示される。
2. いずれか1項目だけを変更して保存すると、変更した値だけが反映される。
3. 保存中は4項目、時刻の増減、取消、保存、閉じる操作がすべて使用できず、連打しても二重保存されない。
4. 自分の保存後に「別の画面で更新された」警告が一瞬表示されず、編集画面が閉じた後の一覧へ新しい値が反映される。
5. 別画面で同じ通常設定が変わった場合は保存を止め、「最新値を読み直す」で入力を作り直せる。
6. 会社管理者以外とsuper-userには編集操作が表示されず、通常設定を保存できない。

2026-08-30に利用者が実際の利用環境で上記を確認し、通常設定の最終UI acceptanceを完了しました。

Company設定には会社デフォルト取極めの編集欄はありません。現場固有の取極めは現場詳細で引き続き管理します。保存済みの旧Company既定値は、別のdata migrationを行うまで削除しません。

## ユーザー設定

**URL:** `/settings/users`  
**ナビゲーション:** 管理者メニュー > ユーザー設定

### 概要

このテナントに所属するユーザーアカウントの一覧を表示・管理します。

### 主な操作

| 操作               | 説明                                                               |
| ------------------ | ------------------------------------------------------------------ |
| 一覧表示           | 登録されているユーザーをメールアドレス順で一覧表示します           |
| ユーザーの追加     | 一覧上部の追加ボタンから新規ユーザーを招待・作成できます           |
| ユーザー情報の編集 | `users:write`を持つ管理者が、他の非管理者ユーザーのロールと通知受信設定を編集できます |
| 有効化・無効化     | 会社管理者が、同じ会社の別の本登録非管理者ユーザーを有効化・無効化できます |
| 管理者変更         | 現在の会社管理者が、同じ会社の有効な本登録非管理者ユーザーへ管理者権限を移譲できます |

ユーザー編集では、メールアドレス、表示名、タグサイズ、会社・管理者・仮登録・有効状態、Employee紐付けを変更できません。自分自身と会社管理者のロールも変更できません。

保存、作成、削除、有効化・無効化、管理者変更の処理中は、同じ対象への同じ操作を再送できません。失敗時は入力内容と対象を確認して再試行できます。

新規作成したUserは本登録前の仮登録ですが、2026-08-21時点のUser一覧には「仮登録」の明示表示がありません。emailと表示名で対象を確認してください。Employee詳細のユーザー情報では「仮登録」と表示されます。

### ユーザーロールについて

ユーザーに付与するロールにより、アクセスできる画面・操作が制限されます。  
ロールの設定はシステム管理者に確認してください。

## 退職・アカウント削除履歴

**URL:** `/settings/lifecycle-history`
**ナビゲーション:** 管理者メニュー > 退職・アカウント削除履歴

会社管理者は、自社で実行した従業員退職、単独ユーザー削除、誤退職訂正を新しい順に確認できます。1ページ20件で、「前へ」「次へ」を使って移動します。検索、絞り込み、CSV出力、全件数表示はありません。

状態は「処理中」「再処理中」「完了」の3種類です。「アカウント削除対象あり」は、その操作にUser accountの削除対象が含まれることだけを示し、削除処理の完了を意味しません。削除済みのUserを現在のUser一覧から引き直さず、履歴に保存された最小情報だけを表示します。

画面を離れた場合、サインアウトした場合、会社管理者権限を失った場合は、表示中の履歴とページ情報をブラウザのメモリから破棄します。履歴はブラウザへ永続保存されません。
