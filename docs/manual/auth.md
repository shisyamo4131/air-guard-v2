# サインイン・アカウント登録

## サインイン

**URL:** `/auth/sign-in`

アプリを利用するにはサインインが必要です。

### 手順

1. メールアドレスとパスワードを入力する
2. サインインボタンをクリックする
3. 認証が成功するとダッシュボードへ遷移する

### エラーについて

| エラーメッセージ                             | 原因                                       |
| -------------------------------------------- | ------------------------------------------ |
| メールアドレス、パスワードをご確認ください。 | 入力内容が誤っている                       |
| このアカウントは無効化されています。         | 管理者によってアカウントが無効化されている |
| メールアドレスの形式が正しくありません。     | メールアドレスの形式に誤りがある           |

## 管理者アカウント登録

**URL:** `/auth/sign-up-admin`

会社（テナント）を新規に作成する場合に使用します。登録した会社の管理者アカウントが作成されます。

> **注意:** このページは新規テナントを作成するためのものです。既存テナントに所属するユーザーの追加は [ユーザー設定](./settings.md) から行います。

### 入力手順（3ステップ）

**ステップ 1 - 認証情報**

| 項目               | 説明                                         |
| ------------------ | -------------------------------------------- |
| メールアドレス     | ログインに使用するメールアドレス（重複不可） |
| パスワード         | 6文字以上                                    |
| パスワード（確認） | 上記と同じパスワードを再入力                 |

**ステップ 2 - 会社情報**

| 項目           | 説明             |
| -------------- | ---------------- |
| 会社名         | 会社の正式名称   |
| 会社名（カナ） | 会社名のフリガナ |

**ステップ 3 - 管理者情報**

| 項目   | 説明                     |
| ------ | ------------------------ |
| 表示名 | アプリ内で表示される名前 |

### 登録完了後

登録が完了すると、確認メールが送信されます。メール内のリンクをクリックしてメール認証を完了させてください。
