# 管制業務

管制業務では、現場の稼働予定の作成・管理から作業員の配置、稼働実績への変換までの一連の流れを管理します。

---

## (Beta) 稼働予定管理

**URL:** `/operation-schedules`  
**ナビゲーション:** 管制業務 > (Beta) 稼働予定管理

> **お知らせ:** この画面は現在ベータ版です。

### 概要

現場ごとの稼働予定をカレンダー形式の一覧で管理します。作業員の配置は行わず、主に**長期間にわたる現場の稼働スケジュール**を把握・管理することが目的です。

### 主な機能

- 月単位のカレンダー形式で全現場の稼働予定を一覧表示
- 現場稼働予定の新規作成
- 各日・現場の必要人数の確認

### 画面操作

| 操作           | 説明                                                                  |
| -------------- | --------------------------------------------------------------------- |
| 月の切り替え   | ツールバーで表示する月を変更できます                                  |
| 並び順の変更   | ツールバーの並べ替えボタンで現場の表示順を変更できます                |
| 稼働予定の作成 | ツールバーの追加ボタンから新規作成できます                            |
| セルのクリック | 日付×現場のセルをクリックすると、その日の稼働予定を選択・確認できます |

### 注意事項

- 稼働予定は稼働日から60日が経過すると自動的に削除されます。復元はできません。

## 配置管理

**URL:** `/arrangement-manager`  
**ナビゲーション:** 管制業務 > 配置管理

### 概要

稼働予定に対して作業員（従業員・外注先）を配置し、**配置通知を送る**ことができます。また、既に配置された作業員の変更も行えます。

稼働予定の作成・編集も可能ですが、主な用途は**作業員の配置と通知**です。

### 画面レイアウト

- **左側のフローティングウィンドウ（作業員選択）**: 利用可能な従業員・外注先が一覧表示されます。ここからドラッグして稼働予定に配置します。
- **スケジュールテーブル**: 日付×現場の形式で稼働予定が表示されます。

### 作業員の配置手順

1. フローティングウィンドウを開く（画面内のボタンまたは操作から）
2. 配置したい従業員または外注先を確認する
3. 対象の作業員をドラッグして、配置したい稼働予定のセルにドロップする
4. 配置が完了したら、配置通知を送信する

### 配置通知について

配置通知は、作業員に対して稼働予定の情報（日時・現場など）を通知するものです。通知を作成すると、作業員側のアプリで確認できます。  
配置通知が作成されている場合、後の[上下番確定処理](./operation-results-generator.md)では通知上の**実際の勤務時間**をもとに稼働実績が作成されます。

### 日別の稼働・配置状況

各日付のヘッダーには、その日の全現場稼働予定を合計した稼働数、配置人数、過不足が表示されます。

- **稼働数**: 各現場稼働予定の必要人数の合計
- **配置人数**: 必要人数の充足判定に含まれる配置人数の合計。配置通知がある場合は通知上の OJT 設定を優先し、実効的な OJT は含みません。
- **不足・超過**: 稼働数と配置人数の差。人数が一致する場合は充足と表示されます。

現場稼働予定カードの過不足も、日付ヘッダーと同じ配置人数を基準に判定します。

各日付列の固定フッターには、配置されている作業員の状態別件数が表示されます。

| 表示 | 状態 |
| --- | --- |
| 仮配置 | 作業員を配置済みだが、配置通知がまだ作成されておらず、通知済みフラグもない |
| 配置済 | 配置通知を作成済みで、作業員がまだ確認していない |
| 確認済 | 作業員が配置通知を確認済み |
| 上番済 | 作業員が上番済み |
| 下番済 | 作業員が下番済み |
| 要確認 | 配置通知と通知済みフラグが一致しない、または配置通知を既知の状態へ分類できない |

状態別件数は配置単位で数えます。同じ作業員が同じ日に複数の予定へ配置されている場合は、それぞれ1件として表示されます。OJT は必要人数を満たす配置人数には含まれませんが、配置状況を確認できるよう状態別件数には含まれます。

### 配置作業員の OJT 表示

配置作業員のタグには、実効的に OJT である場合、資格者アイコンと作業員名の間に OJT 表示が付きます。配置予定と配置通知の両方に OJT 設定がある場合は配置通知を優先し、配置通知がない場合は配置予定の設定を使用します。配置通知側で OJT を外した場合も、その `false` を有効な編集結果として扱います。

作業員名がタグの表示幅に収まらない場合は、資格者アイコン、OJT 表示、連勤警告などを残し、作業員名の末尾を「…」で省略します。

OJT 表示のある作業員は、日付ヘッダーと現場稼働予定カードの配置人数には含まれません。ただし、固定フッターの配置状態別件数には含まれます。

### 連勤の警告

従業員が次のいずれかに該当する場合、関係する双方の配置タグに警告アイコンが表示されます。外注先は連勤判定の対象外です。

- 同じ日の日勤と夜勤の両方に配置されている
- ある日の夜勤と翌日の日勤の両方に配置されている

警告アイコンへマウスポインターまたはキーボードのフォーカスを合わせるか、タップすると、その配置から見た警告理由を確認できます。警告は配置内容を確認するための注意喚起であり、配置の保存を禁止するものではありません。

## 上下番確定処理

**URL:** `/operation-results/generator`  
**ナビゲーション:** 管制業務 > 上下番確定処理

### 概要

稼働日を過ぎた現場稼働予定を**稼働実績**に変換する処理です。配置が完了し、稼働日が過ぎたタイミングで実行します。

「上下番」とは交代勤務の引き継ぎのことを指し、この処理によって予定が実績として確定されます。

### 処理の仕組み

| 条件         | 稼働実績への反映内容                             |
| ------------ | ------------------------------------------------ |
| 配置通知あり | 通知上の実際の勤務時間（actualXXXX）をもとに作成 |
| 配置通知なし | 稼働予定の予定勤務時間がそのまま実績として適用   |

### 取極めが未登録の場合

対象の現場に取極め（単価設定）が登録されていない場合、処理を進めることができません。  
その場合、画面の案内に従って**取極めの仮登録**（すべての単価を1円で設定）を行うことで実績を確定させることができます。後から正しい取極めに更新してください。

### 処理手順

1. 画面に「未確定の稼働予定」が一覧表示される
2. 対象の稼働予定を選択する
3. 取極めが設定されているか確認する
4. 確定処理を実行する
5. 稼働実績が作成される

「上下番を確定する」を押すと、確定処理が終了するまで処理中ダイアログが表示されます。処理中は別の稼働予定を選択せず、完了またはエラーの表示を待ってください。

### 注意事項

- 処理を実行すると稼働実績が作成されます。一度削除すると元に戻すことはできません。
- 取極めが未登録の場合は確定処理を進めることができません（仮登録は可能）。
- 処理中ダイアログは、成功・失敗のどちらの場合も処理終了時に閉じます。
