# 取引先管理

**ナビゲーション:** 取引先管理

警備サービスを発注する顧客企業（取引先）の情報を管理します。

---

## 取引先一覧

**URL:** `/customers`  
**ナビゲーション:** 取引先管理 > 取引先一覧

### 概要

初期表示は契約中の取引先です。「状態」で契約中・契約終了・すべてを切り替えられます。キーワード検索でさらに絞り込みが可能です。

### 画面操作

| 操作     | 説明                                                   |
| -------- | ------------------------------------------------------ |
| 検索     | 検索ボックスにキーワードを入力して取引先を絞り込みます |
| 状態     | 契約中・契約終了・すべての表示対象を切り替えます       |
| 新規作成 | 一覧上部の追加ボタンから取引先を新規登録できます       |
| 詳細表示 | 一覧の行をクリックすると詳細画面へ遷移します           |

新規作成ボタンは、会社管理者または取引先の変更権限を持つ担当者にだけ表示されます。閲覧権限だけの利用者は一覧と詳細を確認できますが、登録・編集はできません。

---

## 取引先詳細

**URL:** `/customers/{id}`

### 概要

取引先の詳細情報を確認・編集します。

### 画面レイアウト

#### 左カラム

**基本情報**  
取引先の基本情報（会社名、住所、電話番号、契約状態など）を表示・編集します。

**請求・回収条件**  
取引先ごとの請求と入金に関する条件を設定します。

| 設定項目   | 説明                                                                                 |
| ---------- | ------------------------------------------------------------------------------------ |
| 入金サイト | 締日から起算した支払期日の設定。取引先請求データの入金予定日の自動計算に使用されます |

> **注意:** 入金サイトを変更しても、**現在の集計期間**の請求データには反映されません。現在の請求データの支払期日は個別に変更してください。将来作成される請求データには新しい入金サイトが自動で適用されます。

編集できる利用者には各欄の編集ボタンが表示されます。入力中に別の画面で同じ欄が変更された場合は保存せず、最新値の読込みを案内します。保存に失敗した場合は入力内容を保持し、保存状態が元へ戻った後に再試行できます。

#### 右カラム

**稼働中現場**  
この取引先に紐づく稼働中の現場の一覧が表示されます。

### 終了・保管

基本情報の編集から契約状態を「契約中」「契約終了」に変更できます。作成時は契約中で登録します。

状態は現在の取引状況を示すだけです。契約終了にしても、稼働中の現場・予定は自動終了せず、もともと取引先を選択できた操作も制限しません。終了日時や理由の入力はありません。詳細は[現行仕様](../specification.md#取引先現場取極め)を参照してください。

保管・復元は状態編集とは別に、参照関係と操作記録を確認する専用処理を後続で整備するまで提供せず、直接削除も許可しません。

この改修の適用・検証状況は[状態編集ロードマップ](../roadmaps/customer-status.md)を参照してください。localの実装とDevでの利用開始は別です。
