# 外注先管理

**ナビゲーション:** 外注先管理

警備員を派遣してもらう特定の協力会社（外注先）の情報を管理します。
外注先から調達した作業員は、従業員と同様に稼働予定へ配置できます。
同じ外注先から複数人を配置する場合は、その外注先を配置明細へ複数回登録します。

---

## 外注先一覧

**URL:** `/outsourcers`  
**ナビゲーション:** 外注先管理 > 外注先一覧

### 概要

契約中の外注先を一覧で表示します。キーワード検索で絞り込みが可能です。

検索ボックスが空の状態では、最近更新された10件が表示されます。

### 画面操作

| 操作     | 説明                                                   |
| -------- | ------------------------------------------------------ |
| 検索     | 検索ボックスにキーワードを入力して外注先を絞り込みます |
| 新規作成 | 会社管理者またはmanagerは、一覧上部の追加ボタンから契約中の外注先を新規登録できます |
| 詳細表示 | 一覧の行をクリックすると詳細情報を確認できます。会社管理者またはmanagerは編集できます |

外注先名は20文字、カナは40文字、略称は6文字、外注先コードは10文字、備考は200文字まで入力できます。ほかの画面で同じ項目が先に更新された場合は保存せず、入力を残したまま最新情報の再読込を案内します。
