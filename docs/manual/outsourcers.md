# 外注先管理

**ナビゲーション:** 外注先管理

警備員を派遣してもらう外部の会社・個人（外注先）の情報を管理します。  
外注先から調達した作業員は、従業員と同様に稼働予定へ配置できます。

---

## 外注先一覧

**URL:** `/outsourcers`  
**ナビゲーション:** 外注先管理 > 外注先一覧

### 概要

契約中の外注先を一覧で表示します。キーワード検索で絞り込みが可能です。

検索ボックスが空の状態では、最近更新された10件が表示されます。

### 画面操作

| 操作     | 説明                                                   |
| -------- | ------------------------------------------------------ |
| 検索     | 検索ボックスにキーワードを入力して外注先を絞り込みます |
| 新規作成 | 一覧上部の追加ボタンから外注先を新規登録できます       |
| 詳細表示 | 一覧の行をクリックすると詳細情報が確認できます         |
