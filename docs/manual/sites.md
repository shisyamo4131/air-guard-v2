# 現場管理

**ナビゲーション:** 現場管理

警備業務を行う拠点・場所（現場）の情報を管理します。取引先が未定の場合は取引先名だけで仮登録でき、後から取引先を設定できます。一度設定した取引先を未設定へ戻すことはできません。

---

## 稼働中現場一覧

**URL:** `/sites`  
**ナビゲーション:** 現場管理 > 稼働中現場一覧

### 概要

現在稼働中（契約中）の現場を一覧で表示します。キーワード検索で絞り込みが可能です。

### 画面操作

| 操作     | 説明                                                 |
| -------- | ---------------------------------------------------- |
| 検索     | 検索ボックスにキーワードを入力して現場を絞り込みます |
| 新規作成 | 一覧上部の追加ボタンから現場を新規登録できます       |
| 詳細表示 | 一覧の行をクリックすると詳細画面へ遷移します         |

現場情報の閲覧権限だけを持つ利用者は一覧と詳細を閲覧できますが、新規作成・基本情報・取引先・取極めの変更・稼働終了はできません。これらの操作は会社管理者または現場の書込み権限を持つ担当者だけに表示され、保存時にも権限を再確認します。

## 稼働中現場詳細

**URL:** `/sites/{id}`

### 概要

現場の詳細情報を確認・編集します。取極め（単価設定）の管理や稼働予定の確認もこの画面で行います。

### 画面レイアウト

#### 左カラム

**基本情報**  
現場の基本情報（名称、住所など）を表示・編集します。  
基本情報の保存は、取引先や取極めを同時に書き換えず、画面を開いた後に同じ項目が別画面で変更された場合は競合として保存を止めます。

**取引先情報**  
この現場に紐づく取引先を確認・変更できます。

#### 右カラム

**稼働予定**  
この現場の月単位の稼働予定を一覧で確認できます。表示月の変更も可能です。

#### 下部

**取極め情報**  
この現場に設定された取極め（稼働単価・計算ルール）を管理します。  
取極めは**適用開始日**・**曜日**・**勤務区分（日勤/夜勤）**の組み合わせで登録します。

> **取極めについての注意事項:**
>
> - 適用開始日付以降の稼働実績に対して単価が適用されます
> - 途中で単価などの情報を変更しても、既存の稼働実績には反映されません
> - 同じ適用開始日付・曜日・勤務区分の組み合わせを重複して登録することはできません

採用済みの改修方針では、取極めの作成・編集・削除は`sites:write`を持つ担当者だけが行います。単価は0〜10,000,000円の整数、休憩・規定実働は0〜1,440分の整数、締日は月末・5日・10日・15日・20日・25日に限定します。0円は保存できますが確認警告を表示し、休憩は勤務区間を超えて設定できません。

適用済みの取極めも編集・削除できますが、既存の稼働実績が保持する取極めは変わりません。変更後の内容は今後作成する実績、または明示的に取極めを再適用する実績にだけ使われます。取極めmaster専用の変更履歴・revision・承認workflowは設けません。

> **改修中の注意:** 取極めの書込み権限は画面・保存直前・Firestore Rulesで強制済みです。数値範囲・0円警告・重複等の内容検査はまだ未実装であり、SITE-06の実装と検証が完了するまでは、その部分を実装済みの保護として扱わないでください。

基本情報・取引先・取極めはそれぞれ独立して編集・保存します。変更がない場合は書込みを行わず、保存に失敗した場合は入力内容を保持します。取引先を設定または変更した場合、現場には表示と取極め判定に必要な取引先情報だけを保存し、既存の稼働実績が保持する取引先・取極めsnapshotは更新しません。

### 現場情報の反映時点

採用済みの改修方針では、稼働予定は最新の現場情報を表示し、稼働実績は作成時点、確定請求書は確定revisionの現場・取引先・取極め情報を保持します。現場情報を後から変更しても、既存の稼働実績と確定請求書は自動更新しません。

> **改修中の注意:** 現行の請求書PDFは生成時の現場名を取得するため、現場名を変更すると過去請求書の再生成表示が変わる場合があります。snapshot対応が完了するまでは履歴再現性が保証されません。

### 現場の稼働終了

稼働終了した現場は稼働中現場一覧には表示されなくなります。

採用済みの改修方針では、工期終了後のACTIVE現場へ「工期終了済み」「自動終了予定」「工期終了済み・予定あり」のChipと自動終了予定日を表示します。工期終了日の90日後になり、当日以降の予定と未実績化予定がない場合だけ自動終了します。工期未設定または予定がある現場は自動終了しません。

終了済み現場も、残工事等のため新しい稼働予定から選択できます。候補ではACTIVEを先、終了済みを後に分け、「終了済み」Chip、取引先、code、住所等を表示します。終了済み現場を選ぶ際は確認を表示し、選択だけで稼働中へ戻しません。単発の残工事は終了済みのまま扱い、継続的な再開は権限を持つ担当者が理由と新しい工期を登録します。

終了操作は理由を必須とし、現在以降の予定または未実績の予定が一件でもある場合は保存しません。終了済み現場は通常編集できませんが、終了済み表示と確認を経て残工事などの単発予定へ使用できます。継続して再開する場合は理由と新しい工期を入力します。再開しても取引先、既存予定、実績、請求、取極めは自動変更されません。

工期終了後は「工期終了済み」「自動終了予定」を表示し、予定情報を全件確認できた画面では「工期終了済み・予定あり」も表示します。自動終了はJSTで工期終了日の90日後以降、将来予定と未実績予定がない場合だけ行います。Dev反映前には既存予定の必須field欠損有無を確認し、欠損があれば自動終了を有効化しません。

### 現場の削除

採用済み仕様では、誤登録・重複で、稼働予定・実績・請求・通知・履歴等から一度も参照されていない現場だけをアーカイブできます。通常の利用終了には「稼働終了」を使用します。参照済みの現場はアーカイブできません。

> **改修中の注意:** 安全な専用アーカイブ処理と全参照保護が完了するまで、現場の削除・アーカイブ操作は画面に表示されず、clientからのSite削除とarchive書込みも拒否されます。誤登録をアーカイブする機能はSITE-05で実装予定です。通常画面からの復元は提供しません。

## 終了現場検索

**URL:** `/sites/terminated`  
**ナビゲーション:** 現場管理 > 終了現場検索

### 概要

稼働終了した現場をキーワード検索で検索します。  
検索ボックスが空の状態では現場は表示されません。名称を入力すると、稼働終了した現場を検索します。

### 終了現場の詳細表示

一覧の行をクリックすると詳細画面へ遷移します（稼働中現場と同じ詳細画面が開きます）。
