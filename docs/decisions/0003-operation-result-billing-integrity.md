# 0003 稼働実績と請求の整合性

- 日付: 2026-08-03
- 状態: Accepted
- 関連仕様: 稼働実績、請求・税・丸め
- 置換対象: なし

## 背景

稼働実績は勤怠と請求の双方の元データであり、取極め未設定、締日未設定、確定後の編集によって不整合が生じ得る。

## 決定

取極めがない稼働実績も業務記録として保存できるが、原則として理由付きの無効状態にし、請求へ反映しない。請求で確定した稼働実績はロックし、更新・削除を拒否する。売上へ連動しない実績だけ明示的な許可で取極めなしを有効とする。

## 理由

現場実績の記録を失わずに、未確定単価が請求へ混入することを防げるため。

## 代替案

- 取極め未設定時に実績作成を全面拒否する案: 現場記録を後回しにし、欠落を招くため採用しない。
- 未確定単価をゼロ円で自動請求する案: 請求漏れを見落としやすいため採用しない。

## 影響

- 利用者: 無効理由を解消してから請求へ反映する。
- データ: 実績、取極め、請求、勤怠の参照関係を保つ。
- 実装: 非同期更新では重複実行とロックを考慮する。
- 確認: 取極めなし、許可あり、ロック済みの各ケースをユーザーが確認する。
- 運用: 未解消の無効実績を把握できる必要がある。

## 移行

なし。既存の設計判断を現行 ADR として記録した。

## 再検討条件

取極め以外の単価確定フロー、承認ワークフロー、請求版管理を導入する場合。
