# 0004 Codex とユーザーの確認責務

- 日付: 2026-08-03
- 状態: Superseded
- 関連仕様: 現段階の完了条件
- 置換対象: [0005](0005-multi-agent-and-emulator-testing.md)

## 背景

試験運用中の環境、秘密情報、Firebase 外部状態を Codex が安全かつ完全に再現できず、従来から動作確認はユーザーが担当している。

## 決定

Codex はコード・設定・文書の変更と読み取りによる差分確認を担当する。ビルド、テスト、エミュレーター起動、デプロイを含む動作確認は行わず、確認観点を提示し、ユーザーが対象環境で判断する。

## 理由

実環境に対する権限と責任の境界を明確にし、外部状態の変更や秘密情報の誤使用を避けるため。

## 代替案

- Codex が常に自動テストとビルドを実行する案: 現在のプロジェクト方針と確認環境に合わないため採用しない。

## 影響

- 利用者: 変更後の確認を実施し、問題ないか判断する。
- データ: Codex の確認目的で実データを変更しない。
- 実装: Codex は確認しやすい観点と必要な手順を提示する。
- 確認: 実施者と結果を完了報告で区別する。
- 運用: デプロイなどの外部操作は別途明示的承認を要する。

## 移行

なし。既存の作業方針を ADR として明文化した。

## 再検討条件

隔離された CI と自動テストが整備され、ユーザーが Codex にその実行を明示的に許可した場合。
